01 / Causal input

One frame per second.
Only what is available.

A causal surgical video stream sampled at one frame per second. At each step, only frames and dialogue already available may be used; persistent memory can retain earlier observations.

02 / Dataset construction

Two label sources.
One procedure identity.

Cholec80 supplies phase and tool labels; CholecT50 supplies instrument-action-target annotations and complementary tool visibility. Shared recordings are grouped by procedure and loaded once with their labels combined.

03 / Procedure-level splits

A shared recording
stays in one split.

The manuscript reports 53 training, 11 validation and 21 test procedures. A shared recording stays in one split, preventing the same procedure from appearing in both training and test through different dataset names.

When the interaction happens

Five temporal modes

A mode describes the relationship between a request, the supporting evidence and the moment of response.

Compare the interaction triggers and response timing of the five temporal modes.

About the examples

Task examples are label-derived reference targets from CholecT50 VID06, not additional model predictions. Choice letters are omitted and categorical names are spaced for readability. Structured examples retain the canonical vocabulary. Recorded model examples appear in the separate demonstration section.

RT

Real-time perception

3 tasks

What is happening now?

Answer an explicit question about the current surgical scene. The relevant evidence is available when the question arrives.

Evidence
Current phase, visible instruments, action triplets or the anatomical target.
Output
A categorical scene description.
Evaluation
Accuracy
T1S1 · Workflow

Current phase recognition

Identify which stage of the surgical workflow is being performed now.

Evidence, timing & example
Available evidence
The current scene and its annotated phase.
Answer format
A canonical phase category; evaluated as a categorical choice.
Valid response time
Target the query instant; evaluation accepts the reply within three seconds.
Scoring rule
Accuracy: the selected phase must match the reference phase.

BM

Backward memory

5 tasks

What happened earlier?

Answer a present question using the accumulated procedure history. Duration, first-appearance, count and order questions deliberately require evidence older than the recent visual window; progress summaries can also include recently confirmed events.

Evidence
Earlier phase intervals and instrument-action-target events retained in memory.
Output
A duration, timestamp, count, ordered structure or structured progress summary.
Evaluation
Task-specific accuracy / structured F1
T4S1 · Workflow

Completed-phase duration

Recall how long an earlier, completed phase lasted.

Evidence, timing & example
Available evidence
A completed phase interval. The query is delayed until the confirming evidence has left the configured recent visual window.
Answer format
A numeric duration in seconds.
Valid response time
Answer the retrospective question within three seconds.
Scoring rule
Duration accuracy with a 20% relative-error tolerance.
Label-derived reference · T4

VID06, Preparation spans 00:00-00:55; question at 01:42.

Example request
How long did the Preparation phase last?
Reference target
55 seconds.
T7S2 · Instrument & action

First instrument appearance

Recover when a named instrument first became visible earlier in the procedure.

Evidence, timing & example
Available evidence
The first stable tool appearance. Independent visibility labels are used where available, including visible tools without an active triplet.
Answer format
A source-video timestamp in mm:ss.
Valid response time
The first appearance has left the recent visual window before the question; reply within three seconds of the query.
Scoring rule
Timestamp recall with an absolute tolerance of ten seconds.

T11S3 · Anatomy

Anatomical handling order

Recall which of two structures was first handled or clipped.

Evidence, timing & example
Available evidence
The first annotated handling or clipping onset for each structure. Onsets must be at least ten seconds apart; the relevant confirmations precede the recent visual window.
Answer format
One of the two named anatomical structures.
Valid response time
Answer the retrospective order question within three seconds.
Scoring rule
Accuracy of the two-choice order decision.

T12S4 · Documentation

Surgical progress summary

Summarize the completed workflow and confirmed events available at an intermediate point.

Evidence, timing & example
Available evidence
All confirmed completed phases and first-occurrence events before the query. This task can include recently confirmed events as well as long-term history.
Answer format
Structured phase intervals followed by timestamped first-occurrence events.
Valid response time
Reply within three seconds of the progress query; include only information confirmed by that point.
Scoring rule
S-F1 averages phase-interval and event F1. Canonical phase/event names must match; interval boundaries and event timestamps are matched within 30 seconds.

Example request

FP

Forward proactive QA

2 tasks

Tell me when it happens.

Keep an explicit request pending while watching the stream, then answer once its specified future event begins. The question arrives before the evidence.

Evidence
The requested event must become visible later in the stream.
Output
A notification that the requested event has begun.
Evaluation
Timing accuracy (T-Acc)
T5S1 · Workflow

Requested phase-start notification

Remember a request to announce the start of a specified future phase.

Evidence, timing & example
Available evidence
A named phase begins after the query. Generated queries normally precede the event by 10-120 seconds.
Answer format
A start notification containing the requested phase.
Valid response time
Wait for phase onset b, then reply inside [b, b + 10 s], capped by video length.
Scoring rule
T-Acc: the first reply attributed to this pending request must have the required start/phase content and fall inside the window. A premature or late reply does not become correct by repeating it later.
Label-derived reference · T5

VID06, query 21:32; phase starts 23:26; valid reply 23:26-23:36.

Example request
Tell me when the GallbladderDissection phase starts.
Reference target
The gallbladder dissection phase has started.
T9S2 · Instrument & action

Requested action-start notification

Wait for a named instrument to begin a specified action, then notify the user.

Evidence, timing & example
Available evidence
A future labeled triplet onset. The first onset of each instrument-verb pair is used so the requested event is unambiguous.
Answer format
An action-start notification naming the instrument and verb; the reference text also names the target.
Valid response time
Queries normally arrive 10-120 seconds before the event. The valid reply window is [event onset, event onset + 10 s], capped by video length.
Scoring rule
T-Acc: the first attributed reply must contain the required start, instrument and action content and arrive inside the window.
Label-derived reference · T9

VID06, query 00:04; event 00:15; valid reply 00:15-00:25.

Example request
Tell me when the grasper starts to retract.
Reference target
The grasper has started to retract the gallbladder.

PA

Proactive alert

2 tasks

Speak when the workflow calls for it.

Issue an alert without an explicit user question. A transition alert follows the new phase onset; a preparation reminder is due before it.

Evidence
An annotated phase boundary and the task's response window.
Output
An unsolicited phase transition or instrument preparation reminder.
Evaluation
Timing F1 (T-F1)
T2S1 · Workflow

Phase-transition alert

Announce entry into a new phase without waiting for a question.

Evidence, timing & example
Available evidence
The annotated onset b of the next surgical phase.
Answer format
A transition alert naming the new phase.
Valid response time
The valid window is [b, b + 10 s], capped by the last video second.
Scoring rule
T-F1: alerts and reference events are matched one-to-one. A hit requires the transition type, correct phase content and a time inside the valid window. Unmatched alerts and missed events affect precision and recall.

VID06, phase onset 00:55; valid alert 00:55-01:05.

Example request
No user question: an automatic phase alert.
Reference target
Phase transition: entering Calot triangle dissection.
T3S1 · Workflow

Instrument preparation reminder

Remind the team about preparation for an upcoming phase before that phase begins.

Evidence, timing & example
Available evidence
Annotated phase onsets define the target window. Preparation text comes from a fixed phase-to-instrument lookup, such as hook for Calot triangle dissection.
Answer format
The upcoming phase and its associated preparation reminder.
Valid response time
The valid window is [max(0, b - 60 s), b]. The phase onset is the deadline.
Scoring rule
T-F1 with one-to-one matching, an in-window reminder and the required phase/reminder-type content. This task uses the benchmark's fixed preparation rules.
Label-derived reference · T3

VID06, next phase begins at 00:55; valid reminder 00:00-00:55.

Example request
No user question: preparation is triggered by the workflow.
Reference target
Calot triangle dissection is coming next; prepare the hook.

CM

Caption memory

2 tasks

Build a record of the procedure.

Evaluate structured surgical documentation. The end-of-surgery note is requested once; streaming narration continuously produces its own Observe and Summary records without a question.

Evidence
Phase intervals and timestamped instrument or instrument-action-target events.
Output
Structured event and phase records.
Evaluation
Structured F1 (S-F1)
T13S4 · Documentation

End-of-surgery operative note

Assemble the full operation into a structured record once the stream ends.

Evidence, timing & example
Available evidence
All phase intervals and first-occurrence instrument or instrument-action-target events from the procedure.
Answer format
A structured note using phase names, interval boundaries and timestamped events.
Valid response time
The query arrives on the final video second; evaluation accepts the reply within three seconds.
Scoring rule
S-F1 using the same phase/event matching rules as T12, with a 30-second tolerance for boundaries and event times.

T14S5 · Narration

Continuous streaming narration

Write timely observations and phase summaries throughout the stream without being asked.

Evidence, timing & example
Available evidence
The event and phase timeline across the procedure. Evaluation reads the model's own Observe and Summary records; there is no separate question-answer target for this task.
Answer format
Timestamped Observe event records (instruments or instrument-action-target triplets) and Summary phase intervals.
Valid response time
Observe records must be emitted causally within 30 seconds after the corresponding event; their reported timestamps must match within 30 seconds and cannot lie in the future. Phase summaries must follow completion and be emitted within ten seconds; reported interval boundaries must match within 30 seconds.
Scoring rule
S-F1 averages matched phase intervals and Observe events. Summary event counts are record content and are not a separately scored count-accuracy measure in this task.

VID06, two label-derived event examples from the full-video narration target. These are event contents, not a claimed model transcript.

Example request
No user question: continuous record writing.
Reference target
[00:15] grasper | retract | gallbladder [00:58] hook | dissect | gallbladder

Reading the evaluation

Content, timing
and the source-video clock.

The task determines both the required answer and the time at which that answer is valid.

01

Evidence time, deadline, response

a is the earliest valid response time, d is the deadline, and r is the emitted response time. These refer to the source video timeline. Future labels define evaluation targets during construction; future frames are not model inputs.

02

The direct-answer allowance

Direct questions target the query instant; evaluation accepts a reply from the query time through three seconds later. This applies to RT, BM and the end-of-surgery operative note.

03

Categories without choice letters

The formal benchmark uses multiple-choice questions for T1, T6, T10 and T11. This guide and the promotional film show the answer content without option letters.

04

Task scores, then two views

Each task is scored first. A mode or scenario score averages its member tasks; Avg_M averages the five modes and Avg_S averages the five scenarios. The two views group the same tasks by different criteria.

T1-T14 and S1-S5 only; the five-scenario benchmark described in the manuscript. Current research manuscript; no independent remote dataset recount is claimed.
